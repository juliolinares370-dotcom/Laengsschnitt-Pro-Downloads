# Längsschnitt Pro – Download für Windows

Hier erhältst du die Windows-Testversion von Längsschnitt Pro. Dieser Bereich enthält Installations- und Update-Dateien sowie Anleitungen.

## Installieren

[**Längsschnitt Pro für Windows herunterladen**](https://github.com/juliolinares370-dotcom/Laengsschnitt-Pro-Downloads/releases/latest/download/Laengsschnitt-Pro-Setup.exe)

1. `Laengsschnitt-Pro-Setup.exe` herunterladen und starten.
2. Anschließend über das Desktop-Symbol **Längsschnitt Pro** oder das Startmenü öffnen.
3. Projekte im eigenen Arbeitsordner speichern, zum Beispiel unter Dokumente.

Windows 10/11, 64 Bit, aktueller Browser und .NET Framework 4.7.2 oder neuer. Das Setup prüft die .NET-Voraussetzung. Die Testversion hat kein eigenes Windows-Herausgeberzertifikat; Firmenrichtlinien können eine IT-Freigabe erfordern.

## Updates

Einmal installieren genügt. Das Programm sucht bei laufender Anwendung nach Updates und lädt neue Versionen herunter. Nach dem Speichern aller Arbeitsdateien und der separaten Planbearbeitungs-Zusammenstellung auf **Update installieren** klicken. Das Programm startet neu. Über **Updates** rechts oben lässt sich die Suche auch selbst auslösen.

Ohne Internet bleibt die installierte Version benutzbar. Projektdateien werden nicht an den Update-Server gesendet. Projekte außerhalb des Programmordners bleiben bei Aktualisierung und Deinstallation erhalten.

## Vorhandene Projekte

`.lspro`-Projektdateien per Doppelklick oder im Programm über **Öffnen** laden. Ältere JSON-/LSP-Arbeitsdateien über **Öffnen** importieren und anschließend als `.lspro` speichern. Frühere Projektordner über **Bisherigen Projektordner öffnen** laden; `Projektinfo.json` allein enthält nicht das gesamte alte Projekt.

Vor dem ersten Test eine Projektkopie sichern. DXF und PDF über die jeweiligen Exportfunktionen erzeugen. Konvertierte PDF-Geometrie und fehlende CAD-Referenzen fachlich prüfen.
